## 8조 헌법

### H1. 배경 = 검정 OR 흰색 (낮/밤 2분법)

- 라이트 모드: `#ffffff` (배경)
- 다크 모드: `#000000` (배경)
- 그라디언트·메시·노이즈·다른색 배경 = **즉시 FAIL**
- 단색 풀블리드만 허용

**예외 ✗:** 어떤 컬러 배경도 H1 위반.

### H2. 컬러풀 = 박스·시각화·형광펜에만

- 컬러 사용처 = 박스(카드 배경)·시각화(차트·다이어그램·아이콘)·형광펜(텍스트 하이라이트)
- 본문 텍스트 다채색 = FAIL
- 6액센트 팔레트 (color-system.md 참조): 옐로우·민트·핑크·블루·코랄·**보라**

### H3. 형광펜 적극 사용

- 핵심 단어·숫자에 형광펜 배경
- 페이지당 0회 = G7 경고
- 페이지당 9+ = G7 FAIL
- 권장: 1~3개 단어 (페이지 단위)
- 색상: 6액센트 50% 알파

### H4. 글자색 = 검정·흰색·컬러풀만 (회색 원천 금지)

- 텍스트: 검정·흰색·6액센트 만
- 배경: 검정·흰색·6액센트 만
- 보더·라인: 검정·흰색·6액센트 만
- **회색(#888·#666·#ccc·gray·grey 등) = 즉시 FAIL**
- grep 게이트: `grep -E '#[0-9a-f]{3,6}|gray|grey'` 매칭 시 차단

**§EXCEPT 극단 예외 (5% 미만):**
- 비활성 폼 placeholder = 검정 30% 알파 (라이트) / 흰색 30% 알파 (다크)
- 비활성 버튼 = 보라 20% 알파
- **그 외 회색 = 영구 금지**

### H5. 표지·섹션·본문 헤드 = 가장 굵은 웨이트 (900)

- 표지 타이틀: weight 900
- 섹션 타이틀: weight 900
- 본문 헤드: weight 900
- 카드 타이틀: weight 900
- **<900 = FAIL**

### H6. 본문 내용만 가는 웨이트 (300)

- 본문(p, .body): weight 300
- 캡션: weight 400
- ≥600 본문 = FAIL
- "본문이 굵어졌다" = 즉시 롤백

### H7. 최소 폰트 12px (PC 기준)

- 데스크톱: 12px 하한
- 모바일 clamp: 하한 12 (`clamp(12px, ...)`)
- <12 = FAIL
- 캡션·라벨이라도 12 하한 절대

### H8. 반응형 100%

- `<meta name="viewport" content="width=device-width, initial-scale=1">` 필수
- 폰트: clamp 사용
- 터치 타겟 ≥ 44×44px
- ≤640px: 1열
- 횡스크롤 ✗ (`document.scrollWidth === window.innerWidth` at 360/390/480/640/768/1024)
- 한글 줄바꿈: `word-break: keep-all` + `overflow-wrap: break-word`
